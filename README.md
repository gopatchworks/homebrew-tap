# Patchworks Homebrew Tap

Homebrew casks for Patchworks command-line tools.

## Install

```bash
brew install --cask gopatchworks/tap/patchworks-installer
```

Or tap the repository first:

```bash
brew tap gopatchworks/tap
brew install --cask patchworks-installer
```

## Release Maintenance

The `patchworks-installer` cask is generated by GoReleaser from the
`gopatchworks/selfhosted` repository when an installer tag such as `v0.1.0` is
pushed.

The source repository must have a `HOMEBREW_TAP_DEPLOY_KEY` secret containing
the private half of a write-enabled deploy key for this tap repository.
